# Web Development Experience: BoilerFoods Organic Food Website

During my Front-End Web Development course at purdue university, I developed BoilerFoods, a fully functional and interactive web application, showcasing my expertise in HTML, CSS, and JavaScript. This project was built from scratch, starting with a user-centric design created using the Balsamiq tool, which allowed me to visually sketch and prototype the website layout. I transformed the initial designs into a dynamic, responsive, and visually appealing web application tailored to health-conscious individuals seeking high-quality organic vegetables.
